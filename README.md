
# 🏪 Market Management System (Windows Desktop - Java + Swing)

> A robust and user-friendly **Java-based desktop application** for managing all essential market operations — including cashier tasks, warehouse control, and employee management.

---

## 📋 Description

The **Market Management System** is a comprehensive software solution for streamlining daily operations within a market or retail environment. This application is built using **Java** and **Swing GUI**, with an **SQLite** database for efficient local data storage. It is designed for Windows desktop platforms and focuses on usability, speed, and operational coverage.

---

## ✨ Key Features

- 🧾 **Cashier Management**  
  Sales transactions, invoice generation, and secure payment processing.

- 📦 **Warehouse Management**  
  Stock tracking, product registration, quantity adjustments, and inventory reports.

- 👨‍💼 **Employee Affairs**  
  Store employee details, manage work hours, and compute incentives.

- 🖥️ **User Interface**  
  Simple and clean GUI built with Java Swing for fast navigation.

- 💾 **Database**  
  Uses SQLite for lightweight, embedded, and fast data handling.

---
